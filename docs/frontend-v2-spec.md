# DSA Frontend v2.0 商用产品规格书

> 版本：2.1.0_COMMERCIAL | 对标：同花顺iFinD / 东方财富专业版
> 后端基线：v2.1.0 12项优化版 data_loader

## 1. 产品定位

从「后端策略驱动工具」升级为「短中长线交易+政策赛道+资金博弈+全维度风控」一体化商用量化决策终端。

## 2. 设计规范

| 属性 | 值 |
|------|-----|
| 主题 | 深色商用风 |
| 主背景 | `#0F131E` |
| 卡片背景 | `#151A28` |
| 主蓝 | `#1677FF` |
| 上涨红 | `#F53F3F` |
| 下跌绿 | `#00B42A` |
| 风险黄 | `#FF7D00` |

| 字体 | 数字等宽 / 中文无衬线 |

## 3. 首页六大核心模块

1. **系统状态栏** — 版本/运行时长/缓存命中率/接口成功率/黑名单
2. **市场趋势** — 指数走势/趋势评分/行业热度TOP10
3. **最近股票** — 浏览记录/策略选股池/自选看板
4. **风险可视化** — 风险饼图/预警列表/溯源面板
5. **国家长线赛道** — 政策赛道/量化评分/优选个股
6. **资金博弈** — 短线资金TOP榜/长线轮动/基本面博弈得分

## 4. API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/v1/market/trend` | GET | 市场趋势 |
| `/api/v1/stock/recent` | GET | 个人标的 |
| `/api/v1/risk/overview` | GET | 风险总览 |
| `/api/v1/policy/track` | GET | 政策赛道 |
| `/api/v1/game/short` | GET | 短线博弈 |
| `/api/v1/game/long` | GET | 长线博弈 |
| `/api/v1/system/status` | GET | 系统运维 |

## 5. 数据刷新策略

- 行情/个股/资金：10s 增量更新
- 系统运维：60s 更新
- 无全量重载

## 6. 老旧模块兼容

- 传统工具入口：次级卡片，弱化视觉
- 底层数据统一替换为 2.1.0 算法
- 双向联动：新首页→旧回测 / 旧筛选→新面板
