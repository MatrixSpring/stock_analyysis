# stock_analyysis 现存缺陷清单

> 最后更新: 2026-07-28 | 版本: v1.0

---

## 数据层

- [x] 多数据源缺少统一适配器，接口异常直接崩溃，无自动降级切换 → 已修复: `core/data_adapter.py`
- [x] 跨市场时区不统一，A股/港股/美股时间戳混乱，回测因子失真 → 已修复: `utils/time_utils.py`
- [ ] 行情复权逻辑控制零散，大量历史数据不复权
- [x] 缺少数据清洗：停牌、一字板、异常价格、空值未过滤，NaN向上冒泡造成页面崩溃 → 已修复: `core/data_cleaner.py`
- [ ] 无增量抓取逻辑，频繁全量拉取触发第三方接口限流
- [ ] 个股/ETF/指数返回字段不统一，前端偶发KeyError
- [x] 无数据完整性校验，无法识别行情断档、缺失交易日 → 已修复: `core/data_cleaner.py`

## LLM人工智能模块

- [ ] 原生仅支持单模型串行；扩展分支缺少并发锁，重复发起LLM请求造成资源浪费
- [x] 无token自动计算、超长上下文截断，批量分析容易超限报错 → 已修复: `core/llm_engine.py`
- [x] 缺少请求限流、队列控制，高频调用容易密钥封禁 → 已修复: `core/llm_engine.py`
- [x] Prompt全部硬编码于代码，无法在线调试修改 → 已修复: `config/prompt_config.yaml`
- [x] 未强制结构化输出，AI自由文本难以解析量化指标 → 已修复: `core/llm_engine.py`
- [ ] LiteLLM异常捕获粒度不足，超时/鉴权失败缺少分级兜底策略
- [x] 不存在推理缓存，相同参数重复调用产生多余费用与耗时 → 已修复: `core/llm_engine.py`

## 策略 & 回测模块

- [ ] 回测未实现滑点、手续费、涨跌停无法成交仿真，结果过度乐观
- [ ] 无未来函数基础检测机制
- [ ] 选股记录不持久化，无法长期统计策略胜率
- [ ] 因子计算缺少空值防护
- [ ] 无策略快照，无法复现历史选股结果

- [ ] 推演任务内存临时存储，页面刷新丢失日志与结果
- [x] 接口缺少统一Pydantic参数校验，非法参数直接500 → 已修复: `utils/exception_handler.py`
- [x] 缺少骨架屏、空状态、统一异常提示 → 已修复: `EmptyState.vue`, `SkeletonLoading.vue`
- [ ] AI分析报告纯文本展示，未结构化拆分，可读性差
